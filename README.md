# Juma Designs Studio

Build a modern, premium, fully responsive website for **Juma Designs**, a Ghana-based creative and digital design studio.

The website should function as a combination of:
- Creative agency portfolio
- Service catalogue
- Pricing page
- Web development showcase
- Graphic design showcase
- Client onboarding/process page
- Lead-generation/contact page

The goal is to make it extremely easy for a potential Ghanaian client to understand:
1. What Juma Designs does
2. What services are available
3. How much each service costs
4. What the client receives
5. How the client engagement process works
6. What previous work looks like
7. How to contact/start a project

Do NOT make it look like a generic template or corporate SaaS website. It should feel like a **premium Ghanaian creative-tech studio**.

---

# 1. BRANDING & VISUAL DIRECTION

Brand:
**Juma Designs**

Location:
**Accra, Ghana**

Primary brand colors:
- Light brown
- Deep brown
- White
- Very subtle neutral/cream tones where necessary

IMPORTANT:
The actual Juma Designs logo will be uploaded after the initial build.

When the logo is uploaded:
- Extract/derive the primary visual colors from the logo.
- Use the logo's light brown and deep brown tones throughout the interface.
- Do not introduce unrelated bright colors.
- White should remain the primary clean background/accent color.

Visual style:

**Liquid glass + premium creative studio + minimal editorial design.**

Use:
- Glassmorphism cards
- Subtle translucent surfaces
- Soft backdrop blur
- Thin borders
- Soft shadows
- Rounded corners
- Subtle gradients derived from the brown brand colors
- Floating cards
- Smooth hover effects
- Elegant micro-interactions
- Smooth scrolling
- Subtle reveal animations
- Large but controlled typography
- Plenty of whitespace

The design should feel sophisticated rather than flashy.

Avoid:
- Excessive animations
- Neon colors
- Overly dark interfaces
- Huge unnecessary hero images
- Generic AI/SaaS aesthetics
- Excessive rounded "pill" components
- Clutter

The website must look excellent on:
- Mobile phones
- Tablets
- Laptops
- Large desktop screens

Mobile experience is extremely important.

# 19. LIQUID GLASS DESIGN SYSTEM

Use a consistent liquid-glass system.

Glass surfaces should have:
- backdrop blur
- translucent white/brown surfaces
- thin semi-transparent borders
- subtle shadows
- soft highlights

Use brown-tinted gradients very subtly.

Example visual direction:

White background → soft brown atmospheric gradient → translucent glass card → deep brown typography → light brown accent.

The glass effect should remain readable and accessible.

Do not make text low contrast.
